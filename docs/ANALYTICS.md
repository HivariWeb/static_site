# Подключение Яндекс Метрики

Счётчик пока не создан. `site-config.js` содержит `metrikaId: 0`: внешняя библиотека не загружается даже при разрешённой аналитике, а первоначальное cookie-уведомление не показывается. Настройки cookie остаются доступны внизу страницы. Заявки работают независимо от счётчика и его блокировки браузером.

1. Создать счётчик для `https://www.dianaberezovskaya.online/`, указать владельца и предоставить нужные права в кабинете.
2. Согласовать актуальность политики и механизма согласий перед включением.
3. Вписать числовой ID в `site-config.js`, запустить `python tools/prepare-release.py` и опубликовать обновлённые файлы по манифесту.
4. Создать цели типа «JavaScript-событие» с точными идентификаторами ниже.
5. Проверить цели в отладчике Метрики и связать счётчик с нужным кабинетом Директа.

| Идентификатор    | Условие                                        | Что означает                         |
| ---------------- | ---------------------------------------------- | ------------------------------------ |
| `service_view`   | Карточка услуги попала в видимую область       | Интерес, не заявка                   |
| `service_select` | Нажата ссылка записи с указанной услугой       | Выбор, не заявка                     |
| `contact_click`  | Нажата ссылка Telegram, WhatsApp, VK или почты | Переход, не подтверждённое сообщение |
| `lead_created`   | Сервер подтвердил сохранение заявки            | Полученное обращение, не оплата      |

Параметры целей ограничены `service_id` и `channel`. Имя, контакт, поля формы, идентификатор обращения, данные ребёнка и тексты переписки в цели не передаются. Вебвизор, карта кликов и автоматическое отслеживание ссылок выключены.

Стандартная инициализация заменена управляемой: счётчик создаётся только после разрешения аналитики; первый просмотр передаётся с очищенным URL, содержащим только известные рекламные метки. При отзыве вызывается `destruct`, локальные метки источника удаляются; последующие цели не отправляются. Уже переданные данные не удаляются из кабинета одним нажатием этой кнопки.

Источник хранится в sessionStorage до 30 минут и переносится между главной и формой в пределах вкладки. Если посетитель отклонил аналитику, UTM, yclid и ClientID к заявке не прикрепляются. При блокировке хранилища интерфейс продолжает работать; источник между страницами может не сохраниться.

Пример ссылки для Поиска:

```text
https://www.dianaberezovskaya.online/?utm_source=yandex&utm_medium=cpc&utm_campaign={campaign_id}&utm_content={ad_id}&utm_term={keyword}
```

Для дальнейшей ручной квалификации и офлайн-конверсий в приватной заявке предусмотрены рекламные метки, yclid и ClientID, когда есть разрешение. Автоматическая отправка статусов «подходящая заявка», «оплачено» и возвратов ещё не реализована. Клики в мессенджеры не следует использовать как эквивалент оплаченного клиента.

Локальные браузерные проверки используют подмену счётчика и не отправляют тестовые обращения в настоящий Яндекс. Активация и работа конкретного реального счётчика требуют проверки после получения ID.

Официальные справочники: [инициализация](https://yandex.ru/support/metrica/ru/code/counter-initialize), [reachGoal](https://yandex.ru/support/metrica/ru/objects/reachgoal), [офлайн-данные](https://yandex.ru/support/metrica/ru/data/offline-params).
