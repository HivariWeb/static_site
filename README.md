# Сайт Дианы Березовской

Исходники сайта консультанта по детскому сну: https://www.dianaberezovskaya.online/.

Состояние опубликованных файлов сверено с хостингом 23 октября 2026 года. В репозитории сохранена история предыдущей версии сайта.

## Структура

- `index.html` — главная страница, услуги, отзывы и контакты.
- `style.css`, `script.js` — оформление и поведение интерфейса.
- `assets/` — фотографии, сертификаты, отзывы и иконки.
- `offer.html` — публичная оферта.
- `privacy-policy.html` — политика обработки персональных данных.
- `consent-personal-data.html` — согласие на обработку персональных данных.
- `send-email.php` — существующий обработчик почты; форма на главной его сейчас не использует.
- `*_snippet.*` и юридические документы DOCX — вспомогательные материалы существующей версии.

## Локальный просмотр

Откройте папку проекта в VS Code и запустите `index.html` через Live Server. Для проверки серверного PHP потребуется отдельное PHP-окружение.

## Публикация

Работающий сайт размещён на REG.RU. В репозитории нет GitHub Actions для публикации на хостинг. Загрузка файлов на REG.RU выполняется отдельно.

Перед загрузкой файлов сохраняйте резервную копию текущей версии и проверяйте изменения локально. На хостинг не нужно загружать `.git`, локальные настройки окружения, учётные данные и папки аудита/резервных копий.

Пароли и ключи хранятся вне репозитория. Соответствующие исключения заданы в `.gitignore`.
