# Сайт Дианы Березовской

Сайт консультанта по детскому сну: https://www.dianaberezovskaya.online/.

Версия от 23 октября 2026 года доработана по техническому аудиту. Сохранены исходные изображения, цены и условия услуг. Добавлены адаптивные страницы, доступная галерея, отдельная форма записи, защищённое хранение заявок и подготовка к аналитике. Онлайн-оплата не подключена.

## Основные файлы

- `index.html`, `style.css`, `script.js` — главная страница и интерфейс.
- `assets/` — изображения и локальные шрифты Montserrat с лицензией.
- `request.php`, `api/leads.php`, `includes/` — форма и обработка обращений на PHP 8.1+.
- `config/services.php` — серверный каталог услуг; цены в нём должны совпадать с карточками главной.
- `config/hosting.example.php` — пример конфигурации. Рабочий конфиг размещается вне публичной папки и Git.
- `site-config.js` — открытая конфигурация Метрики. ID `0` означает, что счётчик отключён.
- `offer.html`, `privacy-policy.html`, `consent-personal-data.html`, `consent-request.html` — документы.
- `.htaccess`, `robots.txt`, `sitemap.xml`, `404.html` — правила публикации и поисковые метаданные.

## Локальный просмотр с формой

В PowerShell из папки проекта:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\start-preview.ps1
```

Нужен PHP 8.1+. При необходимости укажите `-PhpExecutable "C:\path\to\php.exe"` и свободный `-Port 8081`. Скрипт создаёт отдельное тестовое хранилище вне проекта. Реальные письма в этом режиме отключены; используйте вымышленные контакты.

Для просмотра только статических страниц подойдёт Live Server. Отправка формы требует PHP и приватной конфигурации.

## Подготовка и проверки

После изменения CSS/JS/HTML:

```text
python tools/prepare-release.py
python tests/run-integration.py --php C:\path\to\php.exe
```

Браузерные проверки запускаются в Chrome через CDP и требуют Node.js с WebSocket, а также работающий изолированный PHP-preview. Укажите адрес, напечатанный скриптом запуска:

```text
node --experimental-websocket tests/browser-check.cjs http://127.0.0.1:8080
```

Тесты не отправляют настоящие письма и не используют реальный счётчик. Создают синтетические заявки только в отдельном локальном хранилище. Перед публикацией проверяется целостность файлов по `config/deployment-manifest.json`.

Сайт размещён на REG.RU. GitHub хранит исходники; GitHub Actions для публикации в репозитории нет. На хостинг передаются только файлы из манифеста выпуска. Пароли, заявки, резервные копии, Git и локальный аудит не публикуются.

Файлы `*_snippet.*` и исходные DOCX остаются материалами предыдущей версии; актуальные документы сайта размещены в HTML. Старый `send-email.php` больше не отправляет почту.
